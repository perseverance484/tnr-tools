# Stage 2: Concept

The idea, before any structure. It goes in the sheet's `concept`.

## Template

```
Hook:        <one sentence a player would repeat>
Fantasy:     <what it feels like to face or play>
References:  <analogues and flavour, within copyright: see references/writing.md section 1>
Option A:    <pitch>
Option B:    <pitch>
Option C:    <pitch, optional>
```

Options differ in kind, not in colour: a different role, a different fight shape, a different
payoff. Two flavours of the same idea are one option.

## Exit checklist

- [ ] Each option can be told apart in one sentence.
- [ ] Each option is buildable with what the engine does today (check the build skill before
      promising a mechanic).
- [ ] No option depends on a reward or number the director has not given.

## Decision for the director

"Which one?" The chosen id goes in `concept.chosen`. Until then it stays `AWAITING_RULING`.
