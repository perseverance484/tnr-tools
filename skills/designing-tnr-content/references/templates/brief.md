# Stage 1: Brief

One paragraph the director can agree or correct in ten seconds. It goes in the sheet's `brief`.

## Template

```
Purpose:   <what this is for: a gap it fills, an event beat, a reward it gates>
Audience:  <who fights or plays it: rank or level band, solo or party>
Home:      <where it lives: which quest, hall, dungeon, event node>
Size:      <single | small | event>
```

## Exit checklist

- [ ] The audience is a band, not "everyone".
- [ ] The home is a real place in the game, or a named new one.
- [ ] Nothing in the brief is a number that belongs to the director.
- [ ] `brief.agreed` is true only after the director has agreed it.

## Decision for the director

"Is this the right thing to make?" One card, before any design work. Stages skipped by size are
named on it.
