# The Mother of Echoes: art prompts, one paste-ready block per asset

- **For:** the art director (ChatGPT generates; Claude does intake, processing and upload manifests afterwards).
- **Asset list, priorities and what is built in code or reused:** `docs/design/MOTHER_OF_ECHOES_ART.md`.
- **Generated by** `docs/handoffs/mother_of_echoes_art_prompts.py`; do not hand-edit. AI_AVATAR and SCENE_BACKGROUND blocks are the spec scaffolds rendered by `shotlist.py render_prompt` (house style verbatim, only the subject written); every other block reuses the fixed lines of the named card in `SKYGLASS_ART_PROMPTS.md` verbatim (the script docstring says why per type).
- **Protocol:** `docs/workflows/ISOLATED_ART_GENERATION.md`. **Live-game requests/writes:** 0. **Credentials:** none.

## How to use

1. Open a **fresh chat for each asset**; paste exactly one block (the text inside the fence) and nothing else.
2. Attach **only the files the card names**, each as its own image (never a folder or a sheet). Repo paths are under `perseverance484/tnr-tools`; bare names (`VT00_approved.png`, `base_ink_of_the_void.png`, `material_skyglass_crystal.png`) are in `skyglass_art_refs.zip`.
3. Generate **one candidate at a time**; approve, reject, or ask for a same-subject revision.
4. **Two wrong-subject or wrong-composition results: close the chat** and start again with the same block.
5. Return each **approved original unprocessed**, named by its code (`ME01_raw_...`).
6. Order: **P1 first**, in the order below. ME01 before ME03/ME04 (save it as `ME01_approved.png`); ME10 before ME11/ME12 (save as `ME10_approved.png`); ME14 before ME15-ME17; ME20 before ME19.
