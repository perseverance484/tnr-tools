# Pill, Kunai and High-Tier Consumable Caches — design draft v2

**Status:** DRAFT proposal for dauntless. Nothing here has been pushed, turned into a manifest or
approved. Every chance, quantity, rarity, chassis field, source and name mapping is a
**proposal**. Balance and rewards are dauntless's call (`docs/DOCTRINE.md`; item reference §4).

**v2 scope (dauntless, 2026-10-13):** each cache feeds one consumable family. One feeds pills, one
feeds kunai, and one feeds high-tier consumables such as Mona's Mermaid Song. v1 covered every
craft family and was too broad, so it is superseded.

**Inputs:**
- Census: `reports/crafting_recipe_census/craftable_recipes.json`. It is COMPLETE, from capture
  `81c76fef…`, read on 2026-10-13 at source pin `TheNinjaRPG@641040531`.
- Loot-table data: `caches_draft.json`. This is the single editable source.
- Yield report: `CACHE_YIELD_REPORT.md`, generated by `harness/crafting_caches/check_draft.py`.

## 1. Rules

1. **A cache carries only the ingredients of its target recipes.** The checker fails a cache that
   is missing an ingredient a target needs. It also fails one that carries something no target
   uses.
2. **Reagents only.** Caches hand out no finished consumables. Pill Pack is crafted from the three
   pills, so the pill cache feeds it through their reagents.
3. **Engine law 22 (the drop doctrine) holds.** Every cache quantity is 3, which shares no factor
   with any recipe quantity of that item (1, 2, 5, 10, 20, 30, 40).
4. **No event items.** Godstorm Eclipse Inheritance and the other event-chain materials stay out.
   So do hidden items and trade-only unique items.
5. **One loot-chest mechanic.** Each cache is one item with a single `noncombatconsumereward` and
   independently rolled lines. A second line on the same id adds a bonus range.

## 2. The caches

The numbers below are the draft's placeholders; the report has every line.

### Pill cache (proposed name: Medicine Inro)
- **Targets:** Chakra Pill II, Stamina Pill II, Small Health Pill, and Pill Pack.
- **Lines:** 8, for about 10.5 reagent units per open.
  - Core: Galecrest Sage 3@100%, plus a 3@30% bonus.
  - Glimmer Dust and Mosswolf Tuft at 3@50%.
  - Moonlight Antlers and Sunroot at 3@40%, each with a 3@20% bonus.
- **Opens per craft:** about 1.3 for each Pill II, 2.8 for a Small Health Pill, and 5.6 for a Pill
  Pack.

### Kunai cache (proposed name: Shinobi Tool Pouch)
- **Targets:** the six COMMON THROWN consumables. These are the Katon, Wave, Ikazuchi, Stonefall
  and Zephyrfang Kunai, and Robber's Friend.
- **Bloodthorn Kunai is out** (dauntless, 2026-10-13). Its Mithril Ore would have leaked into 11
  Legendary weapons and armor pieces, and the cache now carries only COMMON/RARE materials.
- **Lines:** 13, for about 12.2 units per open.
  - Core: Iron Ore 3@100%, plus a 3@30% bonus.
  - Each kunai's reagent pair at 3@25%.
- **Opens per craft:** about 2.7 for each kunai.

### High-tier cache (proposed name: Sage's Reliquary)
- **Targets:** Mona's Mermaid Song, Solider Pill, Enemy Pill, and Forbidden Jutsu Scroll: Nexus
  and Rebirth.
- **Lines:** 7, for about 5 units per open.
  - Core: Cracked Auditory Core 3@50%. It feeds three of the five targets.
  - Tempest Thorn, Lunaris Bloom, Heart of Kuraokami, Fujin's Breath and Voidshade Petal at 3@20%.
  - Parchment Core at 3@15%.
- **Opens per craft:** about 17 for the three Cracked Auditory Core recipes, and about 22 for each
  scroll.

## 3. Proposed chassis (all three)

This is cloned from the item reference §5 chest chassis:
- `CONSUMABLE` / `ITEM`, rarity `COMMON`;
- `destroyOnUse` and `preventBattleUsage` true;
- `stackSize 999`, `canStack` true;
- `inShop` and `canBeTraded` false;
- `cost 1`, `requiredLevel 1`;
- `battleDescription "Supply cache"`;
- created **hidden**. Publishing is a separate action that dauntless owns.

## 5. Name options

Existing chests are named things like "Genin Supply Cache", "Common Gatherer's Chest" and
"Storm War Cache". None of the names below appear in the repository's seed item catalog
(`answers/names_item.json`). That catalog is old, so recheck the final picks live.

| Cache | Recommended | Alternatives |
| --- | --- | --- |
| Pills | **Medicine Inro**. An inrō is the lacquered case Edo-period travellers carried pills in. | Apothecary's Satchel, Herbalist's Satchel, Field Medic's Kit |
| Kunai | **Shinobi Tool Pouch**. It is the hip pouch kunai are carried in. | Kunai Smith's Bundle, Armorer's Cache, Ninja Tool Pouch |
| High-tier | **Sage's Reliquary**. Rare relic reagents and Forbidden scrolls, kept sealed. | Forbidden Reliquary, Hermit's Strongbox, Sealed Lacquer Box |

The two coherent alternatives are:
- **Craft-trade:** Apothecary's Satchel, Armorer's Cache, Forbidden Reliquary.
- **The original working names:** Field Supply Cache, Armorer's Cache, Reagent Cache.

"Reliquary" is already used by the Skyglass Reliquary, the Ghost Ship chest. If that overlap would
confuse players, pick Hermit's Strongbox instead.
