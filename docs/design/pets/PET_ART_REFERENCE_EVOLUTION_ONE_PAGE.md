# TNR Pet Art — Reference-Led Evolutions

**Goal:** Premium TNR pixel art that makes every species recognizable, but every player's pet unique.

### The three-step flow

**1. Species base image.** I'll provide **one approved reference per species**. It anchors anatomy, silhouette and art quality — **not** fixed colours, markings, aura or pose.

**2. First generation (Rank 1).** Use the **species base image + the pet's rolled palette, markings and aura + a Rank 1 concept**. Generate a unique, transparent sprite. **Save it as this individual pet's reference.**

**3. Evolutions (Ranks 2–10).** Use the **pet's latest accepted image**, plus an **editable concept for that species and new rank**. Evolve its natural features, not random anatomy (tigers shouldn't grow feathers!). Preserve its colours, markings and identity. Each accepted image becomes the reference for the next rank.

> **Species base → unique Rank 1 pet → Rank 2 → ... → Rank 10.**

### What we'd need

**I'll supply:** One base image and **10 short rank concepts per species** (first form + nine evolutions).

**Developer adds:** A base-image upload and editable Rank 1–10 concepts in the species editor. For initial generation, pass the species image; thereafter pass the **individual pet's preceding image**. Same-rank redraws preserve the existing form.

**Art and QC:** Use our approved Kitsune/Dragon/Phoenix as the **premium pixel-art quality bar**, not colour/pose templates. Full-body sprites, correct anatomy, crisp detail, transparent background, no scenery. Keep existing cosmetic choices, moderation, cutout and quality checks.

**No fixed rank pictures and no multi-reference system needed.** The existing generator already accepts one reference image.

**Result:** Consistent species design, unique pets and logical evolutions.
