Use the stable review code or exact name to sort entries. Record final decisions by bloodline ID in `roster.json`; review codes are only a convenient discussion aid.

The 95-record census contains 40 visible D–S candidates including Taiyo Kami, 11 visible H-ranks and 44 hidden records. It excludes null-rank records by the source endpoint’s default filter and is not a complete current-game certification. Public kit evidence is dated 2026-10-01; hidden evidence is dated 2026-09-30.

**Already excluded by direction:** Borrowed Awakening, custom/player-owned bloodlines and bloodlines with no bloodline jutsu. Borrowed Awakening has no resolved bloodline ID in this census; the exclusion is retained without guessing one.

**Do not infer:** hidden = custom; H = custom; zero public jutsu = no jutsu. Six visible H-ranks have hidden-only kits. A record count does not certify acquisition or mode legality.

## How to finish the roster

Confirm core candidates; classify visible H-ranks; review hidden exceptions and the no-jutsu group; add any missing standard or null-rank bloodline by a verified record ID. A user-owned custom record stays excluded even if it is visible or has a full kit. A hidden standard record stays on hold until its intended release/availability is settled.

Once sorted, record decisions/reasons and populate `approved_remaining_ids` with included IDs only, excluding Taiyo Kami. Publish that roster revision alongside the brief before Claude starts the batch.
