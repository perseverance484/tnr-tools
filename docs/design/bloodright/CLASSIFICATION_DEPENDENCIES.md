# Bloodright classification dependencies

Generated by `scripts/bloodright/classification_table.py` from the kit dossiers. Potency is **element-wide** (RUL-2026-10-03-005): a Bloodright modifier reaches matching supported tags on every jutsu of the qualifying element, from any source. Bloodline id, equipment, injected-child provenance and jutsu names are not selectors; equipment only gates castability.

- **element**: one signature element on the kit's damage/pierce rows; it is the classification.
- **multi-element: director review**: several signature elements; the proposal lists all of them, and choosing one, all, or an extension is a director decision.
- **requires classification extension**: no non-None signature element; a new jutsu classification (placeholder named after the bloodline) would be needed. It is not a bloodline-id selector.

`Authored classification` lists kit jutsu whose own rows carry no qualifying element (train.ts `checkJutsuElements` union): they are in scope only if their jutsu records carry the classification as authored data, which needs the proposed jutsu-classification field (ENGINE_GAP_REGISTER G1). `Bloodlines sharing the element` counts other captured bloodlines with jutsu of the element; sharing is expected, and those bloodline jutsu are castable only by their own owners (train.ts 185-188). Off-kit NORMAL/SPECIAL/EVENT/FORBIDDEN coverage is unverified everywhere.
