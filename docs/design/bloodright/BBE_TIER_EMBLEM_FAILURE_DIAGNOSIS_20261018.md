2. **One source per tier:** load the three actual 1254×1254 verified master RGB PNGs with a deterministic image processor. Keep each original filename and SHA immutable. Different RGB ratios, facet-level palette, edge treatment and intrinsic material are still possible **without altering source intensity geometry**. Note: preserving *all* original master intensity necessarily preserves the existing tiny master glint/particle support; any demand to remove even those pixels conflicts with strict pixel-equivalent geometry and would need a separate director-approved variant.
