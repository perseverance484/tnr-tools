# Bloodright open user decisions

Decisions reserved to dauntless under `docs/DOCTRINE.md` (D-reserved-dauntless) and `docs/workflows/DIRECTOR_DECISIONS.md`. None is settled by the drafts; every number in the trees is a proposal within the RUL-2026-10-03-005 ceilings. Each entry gives the practical consequence; recommendations are advisory. Decisions that a ruling has since settled are kept with their resolution so the history stays readable.
