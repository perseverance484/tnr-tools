# Capture retention

Raw captures are durable evidence. Name catalogs do not preserve full records,
AI kits, provenance or pinned-census inputs. Folding rows into seed catalogs is
not sufficient grounds to delete captures or rewrite shared history.

Default startup uses compact task views, so it does not load the capture archive
into model context. Keep the raw evidence reachable and regenerate query views
from it. If storage or clone time later warrants migration, inventory all source
pins and consumers first and plan an evidence-preserving migration separately.
The former keep-N/history-squash recipe is retired; Git history preserves it.
