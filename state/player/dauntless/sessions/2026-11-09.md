## Mechanics learned (for the playbook)
- Battle loop: `combat.getBattle` for version/positions, `combat.performAction {battleId, actionId, longitude, latitude, version}`.
  A call with only `battleId` advances AI turns.
- `usersState` order changes per battle: always match by username.
- Grid is odd-q: from an even column the right-hand neighbours are (x+1, y-1) and (x+1, y);
  from an odd column (x+1, y) and (x+1, y+1). An illegal move returns "Action Move no longer possible" or an empty result.
- Move costs 10 AP; most jutsu 60 AP, self buffs 40 AP; out-of-range jutsu fail with "no longer possible".
- Cooldowns reset each battle.
- Auto combat advances one action per call (no call saving); toggling it off also sets the default off.
- Basic actions include `clear` (strips the target's positive effects): the answer to openers like Sovereign Ascendance.
- Arena opponents: `profile.getAllAiNames {arenaOnly:true}`.
